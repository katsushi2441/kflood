# Kurage 洪水・内水ハザードマップ (kflood)

住所を入れると、その地点が**洪水（河川の氾濫）で何メートル・何日浸かる想定か**と、
**内水（下水道・水路からの浸水）で何メートル浸かる想定か**を、データ時点つきで返します。

- デモ: https://kurage.exbridge.jp/kflood.php/
- 洪水: 国土数値情報「洪水浸水想定区域（1次メッシュ単位）データ 第4.0版」(A31) 国土交通省 — 全国
- 内水: 名古屋市「内水氾濫ハザードマップ（浸水想定・浸水継続時間）」なごや防災オープンデータカタログ（CC BY 4.0）— 名古屋市版を同梱。他の自治体は Shapefile を1つ足せば同じ画面で動く

（リポジトリ・ポート・systemd unit の略称は `kflood`。対外の名前は「Kurage 洪水・内水ハザードマップ」）

## 返すもの

| 項目 | 内容 | 出典 |
| --- | --- | --- |
| 想定最大規模の浸水深 | 0.5m未満／0.5〜3m／3〜5m／5〜10m／10〜20m／20m以上 | A31 想定最大規模（A31_201） |
| 計画規模の浸水深 | 同上（河川整備の目標規模の降雨） | A31 計画規模（A31_101） |
| 浸水継続時間 | 12時間未満〜4週間以上の7段階 | A31 浸水継続時間（A31_301） |
| 家屋倒壊等氾濫想定区域 | 氾濫流／河岸侵食／両方 | A31（A31_401） |
| 内水の浸水深・継続時間 | メートル値と分（自治体データ） | 名古屋市 内水氾濫ハザードマップ |
| 海抜 | 国土地理院 標高API | — |
| 行動の目安 | 立退き避難か、上の階への垂直避難で足りるか | 浸水深3m以上・倒壊区域・3日以上の浸水で立退き |
| マイ・タイムライン | 世帯条件（高齢者・乳幼児・車・上階・ペット）を足して、警戒レベル1〜5の行動表を印刷 | 内閣府 避難情報に関するガイドライン |
| CSV一括判定 | 住所CSV（300行まで）→ 判定CSV | BCP・物件の洗い出し用 |

## 設計の芯

1. **○×ではなく「何メートル・何日」を返す。** 0.5mと5mでは取るべき行動が違う。
2. **「区域外」と「未収録」を必ず区別する。** 取り込んでいない1次メッシュ・自治体で、黙って「区域外」と答えない（`meshes` 表・`naisui_coverage` 表で判定）。
3. **判定には必ずデータ時点と出典を添える。** `datasets` 表に時点が無いデータでは判定しない。
4. **近くに区域があるときは言い切らない。** 住所の座標は町丁目の代表点（khazard で実測 14〜50m のずれ）。250m以内に区域があれば地番での確認を促す。
5. **一次情報への導線を必ず返す。** 判定は参考であって公的な証明ではない。不動産の重要事項説明には自治体の図面そのものを使う。

| 部品 | 中身 |
| --- | --- |
| ジオコーディング | 国土地理院 AddressSearch API（無料・キー不要） |
| 判定 | PostGIS（kflood-db :55434）ST_Contains |

## データ

| 項目 | 値 |
| --- | --- |
| 洪水 出典 | 国土数値情報 洪水浸水想定区域（1次メッシュ単位）A31 第4.0版 国土交通省 |
| 洪水 データ作成年度 | 2022年度（令和4年度）。配布ファイル日付 2023-06 |
| 洪水 収録 | **全国 1次メッシュ104件・21,375,145面**（洪水予報河川・水位周知河川＋その他の河川、配布151ファイル。2026-09-08 取り込み・83分） |
| 内水 出典 | 名古屋市 内水氾濫ハザードマップ（浸水想定 2022-05-27 指定・浸水継続時間 2023-03-07 掲載）CC BY 4.0 |
| 座標系 | JGD2011 地理座標系（EPSG:6668）。名古屋市データは EPSG:2449 から変換 |

土砂災害（khazard）の README に「洪水は2012年版しか無いので扱わない」と書いてあるのは**旧版（都道府県別 A31 v2.2）の話**です。
2021年以降に配布が始まった1次メッシュ単位版（第4.0版）は2015年水防法改正後の「想定最大規模」を含む現行基準で、本製品はこれを使います。

## 使い方

```bash
docker compose up -d                              # PostGIS（データ実体は KFLOOD_PG_DIR で別ディスクに置ける）
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt
.venv/bin/python scripts/load_a31.py 5236 5237    # 1次メッシュ指定（名古屋周辺）
.venv/bin/python scripts/load_a31.py 23           # 都道府県コード
.venv/bin/python scripts/load_a31.py all          # 全国（数十分）
.venv/bin/python scripts/load_nagoya_naisui.py    # 名古屋市 内水
systemctl --user enable --now kflood.service      # または .venv/bin/uvicorn app.main:app --port 18386
curl 'http://127.0.0.1:18386/api/check?q=愛知県名古屋市中川区富田町大字千音寺'
```

`ogr2ogr`（GDAL）が必要です（Ubuntu: `apt install gdal-bin`）。A31 の GeoJSON は GDAL がストリーミングで読めるため、
431MB のファイルを 16 秒・常駐メモリ 120MB で取り込めます（2026-09-08 実測）。

## 他の自治体の内水を足す

`scripts/load_nagoya_naisui.py` の `DATASETS` に、その自治体の配布物（URL・属性名・座標系・出典表記・時点）を1件足して実行します。
判定は `naisui_coverage` の自治体名が住所に含まれるときだけ動くので、画面やAPIの変更は不要です。

## テスト

```bash
.venv/bin/python -m pytest -q tests
```

コード表（浸水深ランク・継続時間ランク・危険区域区分）が国土数値情報のコードリストと一致すること、
取り込みスクリプトと判定が同じ表を使うこと、マイ・タイムラインの避難方針の分岐を固定しています。
