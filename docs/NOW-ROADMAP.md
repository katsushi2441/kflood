# 「いま、どうするか」を状況ページに育てる（2026-09-21）

港区防災ポータル（Salesforce製の運用画面）と名古屋市防災ポータル（リンク集）を実測して比べた結果、
**名古屋市に足りないのはデータでもシステムでもなく、1つの住所について「いま」を束ねる層**だと分かった。
名古屋市は雨量も水位も警報も持っているが、別々のサイトにある。

- 名古屋市水防情報システム(NICOS) https://nagoya-city.mec-weather.jp/ … 雨量・水位・気象警報・土砂・洪水予報
- 上下水道局 雨水情報 https://www.water.city.nagoya.jp/subsys/rainwater/ … レーダー雨量・ポンプ運転状況
- 道路・河川等監視情報システム … カメラ画像
- 災害情報配信 https://www.city.nagoya.jp/1000103.html … 避難情報（kflood が3分ごとに取得中）

**いずれも機械可読な口は無い**（NICOS・愛知県 川の防災情報・上下水道局のいずれも JSON/CSV の参照が0件。2026-09-21 実測）。

だから、新製品を作るのではなく `/now` に足す。住所の入力・判定・避難所の部品は全部ここにある。

## 優先順（上から着手する）

### 1. 気象庁の bosai JSON を取り込む 【2026-09-21 実装済み・`app/jma.py`】

港区の「警戒レベル相当情報」に相当する枠が、これで埋まる。鍵なし・市区町村コード単位で公開されている。
2026-09-21 に疎通と中身を実測した。

- 警報・注意報: `https://www.jma.go.jp/bosai/warning/data/warning/230000.json`（愛知県）
  → `areaTypes[].areas[].code == '2310000'` が名古屋市。`warnings[].code` と `status`。
- 天気予報: `.../bosai/forecast/data/forecast/230000.json`
- 地震: `.../bosai/quake/data/list.json`
- 危険度分布（雨・土砂・洪水）のタイル: `.../bosai/jmatile/data/nowc/targetTimes_N1.json` で時刻一覧
  → kflood は既に国土地理院のタイルを読む実装（`scripts/load_gsi_naisui_tiles.py`）があるので、同じ形で扱える。

### 2. 「出ていない」を常設の枠にする 【2026-09-21 実装済み（気象警報の枠・`/now` と区ページ）】

名古屋市の災害情報配信は、発令が無いと枠ごと消える。港区は「避難情報はありません。」と書く。
kflood は既に「取得できなかったときは発令なしと書かない」を守っているので、その枠を5行に広げる。

1. 気象警報・注意報（取得時刻つき）
2. 土砂災害警戒情報
3. 指定河川洪水予報
4. 市の避難情報（学区別）
5. 近くの避難所の開設状況

**5行とも「発表されていません」と書ける状態を作る。** これが港区との差の本体。

### 3. 避難所の開設状況を前に出す（krefuge の資産の再配置）

港区は「現在の開設状況」が一等地にある。krefuge は名古屋市の退避施設の開設状況（ArcGIS公開）を既に持っている。
`/now` の4番目の枠（近い避難先）に開設状況を出す。

### 4. 配信の履歴を残して見せる（ここが製品の核になる）

港区は1か月で約40件の配信履歴が時刻つきで一覧に残る。名古屋市は事後のお知らせに流れて追えない。
kflood は3分ごとに取得しているので、**保存して「この住所に、いつ何が出たか」を履歴として出せる**。
9月8日の検証（避難情報24件を手で突き合わせた）が、自動でできるようになる。CSV/JSON で配れる形にする。
これをやっている先行例は見当たらない。

### 5. 雨量・水位（優先度は下げる）

NICOS・愛知県 川の防災情報・上下水道局のいずれも機械可読な口が無く、取り込みはスクレイプになる。
規約の確認も要る。先に 1 の危険度分布タイルを入れたほうが、労力あたりの効果が大きい。

## 作らないもの（判断の記録）

- 公共交通・ライフライン・道路規制: JARTIC は API 非公開、停電情報は各社の規約次第。運用負荷の割に効かない。
- 災害用伝言板: NTT へのリンクで足りる。
- 防災行政無線の放送内容: 名古屋市には同報無線を全市で流す運用が無く、データ源が無い。

## 実装の記録（2026-09-21）

- `app/jma.py` … 気象庁の区域表（area.json・class20s 1,805件）を `data/jma_area.json` に置き、
  住所の最長一致で市区町村コードを引いて、府県予報区の警報 JSON から**その市に出ているものだけ**を返す。
  キャッシュ180秒、取れなければ前回値を `stale`、それも無ければ `unavailable`。**「発表なし」とは言わない。**
- `/now` と 区ページ（16区）に枠を追加。`/api/check` の戻りにも `jma` が入る。
- Jinja で `jm.items` と書くと dict の `.items` メソッドに当たる。**`jm['items']` と書く。**
- 全国で動く（東京都港区は「港区に気象警報・注意報は発表されていません」と出る）。
  発令の取り込みは名古屋市だけなので、他市では気象警報の枠だけが埋まる。
